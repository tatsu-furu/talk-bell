# 発表ベル

学会やゼミの「1鈴・2鈴・3鈴」で時間を知らせる発表タイマーです。alt4L（オルタル）の個人開発ツールの1つで、ブラウザの中だけで動きます（サーバーも通信もありません）。一度開けばオフラインでも使えます。

- 設計と決まりは [CLAUDE.md](./CLAUDE.md) にあります。
- アプリ名とサブドメイン（案：`bell.alt4l.dev`）は仮です。

## 使い方

| 操作 | キー |
| --- | --- |
| 開始／一時停止 | Space |
| リセット | R |
| ±1分 | ← / → |
| 全画面 | F |
| 消音 | M |

設定はURLで共有できます。例：`/?talk=15&qa=5&b1=12`（`talk`＝2鈴の時刻（分）、`qa`＝質疑の長さ（分、0で3鈴なし）、`b1`＝1鈴の時刻（分、`off`で使わない）、`mode=elapsed`＝経過時間表示、`mute=1`＝消音）。

## 開発

```
npm install
npm run dev      # 開発サーバー
npm test         # Vitest（時間の計算、ベルを鳴らす判定、URLの読み書き）
npm run build    # dist/ に出力（Service Worker の一覧もここで書き込む）
npm run preview  # dist/ を確認
```

Netlify では `netlify.toml` の設定（`npm run build`、公開先 `dist`）で公開します。ページの CSP は `connect-src 'self'` で、外部には送れません。

## 作りのメモ

- 時間は `setInterval` の回数ではなく、開始時刻との差から毎回計算します（`src/timer.ts`）。
- ベルは「その時刻を初めて超えたとき」に1回だけ鳴ります。タブが裏に回って1.5秒より遅れて気づいたときは、鳴らさず表示だけ更新します（`src/bells.ts`）。
- 音は Web Audio で合成しています（録音は使っていません）。
- 画面を消したりアプリを切り替えたりすると、スマホでは音が鳴りません。
